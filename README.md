# ⚡ بوت بينانس سبوت اللحظي للتداول الفوري (Binance Spot 24/7 Scalper Bot)

بوت تداول آلي فوري مخصص للعمل على منصة **Binance Spot (العقود والتداول الفوري)** على مدار الساعة **24/7 دون أي تجميد أو توقف**، متوافق كلياً مع منصة السحاب **Railway** وخوادم Docker.

---

## 🎯 مميزات التصحيح الجذري والتحويل إلى التداول الفوري (Spot):

1. **التحويل الكامل إلى التداول الفوري (Binance Spot)**:
   - تم تغيير كافة الاتصالات من العقود الآجلة إلى سوق التداول الفوري (`api.binance.com`).
   - إلغاء الروافع المالية والهوامش والمخاطر التصفوية نهائياً؛ التداول يتم بشراء العملة الأصلية وبيعها مقابل USDT.

2. **منع التجميد والتوقف 24/7 (Zero-Freeze Architecture)**:
   - **معالجة خصم الرسوم (Fee Compensation)**: عند البيع، يقوم البوت بقراءة رصيد المحفظة الحر الفعلي للعملة حتى لا يفشل أمر البيع بسبب خصم عمولة المنصة كما يحدث في البوتات التقليدية.
   - **التعافي التلقائي من انقطاع الشبكة وقيود التردد**: معالجة أخطاء 429 و 451 وإعادة المحاولة بذكاء دون توقف المعالج أو الخادم.
   - **خادم فحص صحة متزامن ومستمر (`/health`)**: يضمن استمرار حاوية Railway واستجابتها دون إعادة تشغيل مفاجئة.

3. **استراتيجية القنص اللحظي السريع (Dip & Rebound Momentum Scalper)**:
   - **رادار الدخول (Entry Radar)**: يراقب هبوط السعر عن قمته المحلية اللحظية (`BUY_DIP_MIN_PCT`) مع تأكيد بداية الارتداد السعري (`BUY_REBOUND_CONFIRM_PCT`) وتأكيد تشبع البيع عبر مؤشر القوة النسبية (`BUY_RSI_MAX`).
   - **وقف الربح المتحرك (Trailing Take-Profit)**: يلاحق السعر عند صعوده ويقفل الصفقة فور ارتداده بنسبة محددة (`TRAILING_CALLBACK_PCT`) لتحصيل أقصى ربح ممكن.
   - **حماية رأس المال (Hard Stop-Loss)**: إغلاق فوري في حال كسر السوق بنسبة محددة لحماية المحفظة.

4. **لوحة تحكم مباشرة متجاوبة (Live Dark Dashboard)**:
   - واجهة مستخدم لحظية باللغتين العربية والإنجليزية تعمل على المنفذ `8080`.
   - تعرض سعر السوق الفوري، إشارات الرادار اللحظية، الصفقة المفتوحة، ونسبة الأرباح المحققة مع تحديث تلقائي كل 4 ثوانٍ.

## ⚙️ إعداد المتغيرات في منصة Railway (Variables)

قم بإضافة المتغيرات التالية في تبويب **Variables** في مشروعك على Railway:

| المتغير | القيمة المقترحة | الشرح |
|---|---|---|
| `BINANCE_API_KEY` | مفتاح الـ API | مفتاح بينانس مع تفعيل **Enable Spot & Margin Trading** |
| `BINANCE_API_SECRET` | الرمز السري | الرمز السري لمفتاح الـ API |
| `LIVE_TRADING` | `true` | اجعلها `true` للتداول الحقيقي بأموال حقيقية |
| `SYMBOL` | `BTC/USDT` | زوج التداول الفوري (مثال: `BTC/USDT`, `ETH/USDT`, `SOL/USDT`) |
| `TARGET_ORDER_USD` | `11.0` | قيمة الصفقة الواحدة بالدولار (يجب أن تكون ≥ $10) |
| `LOOP_INTERVAL_SEC` | `5.0` | زمن دورة الفحص اللحظي بالثواني (سرعة التحديث) |
| `BUY_DIP_MIN_PCT` | `0.25` | الحد الأدنى للهبوط اللحظي للدخول (%) |
| `BUY_REBOUND_CONFIRM_PCT` | `0.08` | نسبة تأكيد ارتداد السعر للدخول (%) |
| `BUY_RSI_MAX` | `48` | أقصى قيمة لمؤشر RSI للسماح بالشراء |
| `TRAILING_STOP_ENABLED` | `true` | تفعيل وقف الربح المتحرك |
| `TRAILING_ACTIVATION_PCT` | `0.35` | نسبة الصعود المطلوبة لتفعيل وقف الربح المتحرك (%) |
| `TRAILING_CALLBACK_PCT` | `0.15` | نسبة ارتداد السعر لإغلاق الصفقة بالربح المحقق (%) |
| `STOP_LOSS_PCT` | `0.80` | وقف الخسارة الصارم لحماية رأس المال (%) |
| `PORT` | `8080` | منفذ لوحة التحكم وفحص الصحة |

